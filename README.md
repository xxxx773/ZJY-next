## ✨ 核心功能

### ▦ 工作台

- 展示用户名称、邮箱等个人资料，以及已绑定账号数量和课程数量
- 展示平台公告，并提供常用入口的快捷导航
- 内置问题反馈窗口，便于提交使用建议或遇到的问题

### 🔗 账号绑定

- 支持 **OAuth 授权绑定**：通过授权回调完成账号关联，减少重复输入账号信息的步骤
- 支持 **账号密码绑定**：完成身份校验后建立学习账号连接，便于同步课程、任务与学习记录
- 支持多个已绑定账号的独立管理与按需切换，避免不同账号的数据混淆
- 结合登录认证、权限校验与加密凭据保护机制，降低账号信息在使用过程中的泄露风险

### 📖 课程中心

- 支持按已绑定账号查询课程，展示课程名称、教师、班级、完成进度与成绩等信息

#### 📝 作业与考试

- 查看指定课程下的作业与考试及其完成情况、答案和成绩
- 支持一键填充、自动提交与成绩查看等学习任务操作
- 在具备相应权限时，可进行成绩修改、设备清除、告警解除与退回重做等管理操作

#### 🏫 课程教学

- 查看课程课表，并可按日期筛选、锁定目标课堂
- 支持签到、补签与签到状态调整
- 展示普通签到、手势签到和二维码签到等课堂签到信息

#### 📤 学习进度提交

- 任务提交后由后端持续同步学习状态，完成视频、文档、压缩包等课件的学习进度更新
- 支持课程讨论区回复，便于完成课程互动任务

### 📂 资源中心

- 集中展示学习资源与使用说明
- 提供常用学习入口，便于快速查找资料

## 🧭 学习辅助流程

### 题库更新判断逻辑

```mermaid
flowchart TD
    A[触发采集] --> B{触发来源}
    B -- 绑定账号成功 --> C[采集该账号全部课程]
    B -- 填充并提交成功 --> D[只采集该账号该课程刚提交的任务]
    B -- 后台立即采集 --> E[全量采集 并重置失败/跳过状态]
    B -- 每24小时定时 --> F[全量采集 不重置状态]
    C --> G[SPOC课程]
    C --> H{上次MOOC同步失败?}
    H -- 是 --> I[本次跳过MOOC]
    H -- 否 --> J[尝试MOOC 失败则下次跳过]
    G --> K
    J --> K
    K[遍历课程下的作业/考试] --> L{任务已完成?}
    L -- 未开始/未提交/未完成/进行中 --> K
    L -- 是 --> M{题库已有该考试/作业ID?}
    M -- 是 --> K
    M -- 否 --> N{任务状态?}
    N -- 附件作业 --> K
    N -- 已标记跳过 --> K
    N -- 连续失败>=3次 --> K
    N -- 正常 --> O[快速拉取题目和答案]
    O --> P{拉取结果}
    P -- 无题目且有附件 --> Q[标记附件作业] --> K
    P -- 无题目且提示非作答时间/已截止 --> R[标记跳过] --> K
    P -- 无题目且无提示 --> S[答案未公布 下次再试] --> K
    P -- 有题目 --> T[清洗并按题干去重保存]
    P -- 请求异常 --> U[失败次数+1]
    T --> V[记录题目/课程/任务/试卷ID]
    V --> W[清除该任务失败状态] --> K
    U --> X{失败>=3次?}
    X -- 是 --> Y[暂停该任务] --> K
    X -- 否 --> K
```

### 签到与改签逻辑

```mermaid
flowchart TD
    A[发起签到] --> B{签到方式}
    B -- 普通签到 --> C[校验绑定账号与任务]
    B -- 手势签到 --> C2[校验手势与签到任务]
    B -- 扫码签到 --> C3[校验二维码会话]
    C --> D[提交官方签到接口]
    C2 --> D
    C3 --> D
    D --> E{是否成功}
    E -- 成功 --> F[记录签到日志+审计日志]
    E -- token过期 --> G[刷新token后重试]
    E -- 其他失败 --> H[记录失败日志并提示]
    A2[改签/补签] --> B2[校验账号与签到记录]
    B2 --> C4[解析目标状态 正常/迟到/缺勤等]
    C4 --> D2[调用教师端状态更新接口]
    D2 --> E2{是否成功}
    E2 -- 成功 --> F2[保存状态+审计日志]
    E2 -- 失败 --> G2[记录失败并提示]
```

### 查看答案、一键填充与填充并提交

```mermaid
flowchart TD
    A[打开作业/考试] --> B{选择操作}
    B -- 查看答案 --> C[拉取已完成试卷/成绩记录]
    C --> D[最多探测8个接口变体直到拿全答案]
    D --> E[显示题目/选项/学生答案/正确答案]
    B -- 一键填充 --> F[加载题目]
    F --> G{题库命中?}
    G -- 命中 --> H[直接填正确选项内容]
    G -- 未命中 --> I[AI识别答案]
    I --> J[应用AI答案到未命中题目]
    H --> K[保存草稿 不提交 不触发采集]
    B -- 填充后核对并提交 --> F2[加载题目]
    F2 --> G2{题库命中?}
    G2 -- 命中 --> H2[直接填]
    G2 -- 未命中 --> I2[AI识别答案]
    I2 --> J2[应用AI答案]
    H2 --> K2[保存草稿并提示逐题核对]
    K2 --> L2{用户确认提交?}
    L2 -- 是 --> M2[提交到智慧职教]
    M2 --> N2[成功后只采集该任务题目]
    L2 -- 否 --> O2[保留草稿]
```

### 刷课逻辑

```mermaid
flowchart TD
    A[发起刷课] --> B[校验账号与模式 SPOC/MOOC]
    B --> C[拉取课程课件树]
    C --> D[遍历课件节点]
    D --> E{是否已完成?}
    E -- 已完成 --> F[计数已完成 跳过]
    E -- 否 --> G{是否可刷?}
    G -- 非课件/作业/考试/讨论 --> H[跳过]
    G -- 可刷 --> I[提交学习记录]
    I --> J{提交成功?}
    J -- 成功 --> K[计数成功 等待二次验证]
    J -- 失败 --> L[计数失败]
    D --> M[全部处理完]
    M --> N[二次验证官方同步]
    N --> O[可选:讨论区自动回复]
    O --> P[输出统计 总计/成功/失败/待同步]
```
